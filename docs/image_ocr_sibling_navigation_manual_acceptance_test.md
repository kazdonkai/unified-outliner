# List+Callout（image-ocr）前後移動・breadcrumb 実機受け入れテスト（2026-09-30）

## 1. 目的

Partial Edit Pane で List+Callout（`image-ocr`）の CompositeBlock を開いているときに、以下を実機（Mac の ipad-test vault と iPad）で確認する。

- 同じノート内の `image-ocr` どうしを、前後移動（Previous/Next）で順送り・逆送りできること。
- 補助情報として breadcrumb が表示されること。

設計の詳細は `docs/統合実装ロードマップ_2026-08-05.md` の §3.32（breadcrumb）と §3.33（前後移動）を参照する。

## 2. 対象ノート

`ipad-test/Iriai/70000001_0018_裁判書 村境争論ノ控訴0.md`

- 「## 記録」の下に、`- [ ] ![[files/…_NN.jpg]]` と `> [!OCR]` callout の組が 17 組ある。
- 本文の出現順は画像番号 13 → 07 → 06 → 12 → 04 → 10 → 11 → 05 → 01 → 15 → 14 → 16 → 02 → 03 → 17 → 08 → 09 である。番号順ではないことに注意する。
- この列は、実ノートを本物のパーサで解析した結果と一致することを確認済みである。

## 4. 既知の限界（仕様）

- 開いている組より**上**で行数が変わる外部編集があると、組の位置が一致しなくなり、ペインは既存どおり「利用不可（unavailable）」になる。このとき前後移動は何も読み込まず、行が消える。Tree から開き直せば回復する。これは CompositeBlock のペインが持つ既存の安全動作であり、今回変更していない。
- 移動先ラベルと breadcrumb は、初回ロード・自動再読込・Apply の各時点の状態を示す。クリック先は常にクリック時の本文から解決する。

## 5. 対象外（確認不要）

- `image-quote` への前後移動の適用
- 同じ見出しの下に限った移動
- タイトルでの組の識別
- breadcrumb の文言改善
